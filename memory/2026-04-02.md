## 关键发现

### 1. 飞书私聊发图正确方法
```bash
# 三步走：获取 token → 上传图片 → 发送消息（关键：receive_id_type=open_id）
curl -X POST "https://open.feishu.cn/open-apis/im/v1/messages?receive_id_type=open_id" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"receive_id":"ou_xxx","msg_type":"image","content":"{\"image_key\":\"...\"}"}'
```

### 2. feishu-send-image 脚本优化
- 新增 `parse_chat_id()` 函数自动识别 ID 格式
- 支持：`ou_xxx`（自动识别 open_id）、`oc_xxx`（自动识别 chat_id）
- 新增 `--receive-id-type` 参数显式指定

### 3. DaVinci Resolve 自动化
- 支持 Python 脚本 API
- 可自动化：批量导入、自动应用 Delta Keyer、批量导出
- 文档：https://resolvedevdoc.readthedocs.io
