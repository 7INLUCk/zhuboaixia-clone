## 广场详情页抖音式滑动切换 - 下午主线任务

### 需求
从广场点进作品详情页后，上下滑动切换广场作品，顺序对应广场列表顺序，到底后循环。

### 实现方案（最终版）
**不使用路由跳转，同页面内滑动切换：**
1. 广场列表页存 `sessionStorage.plaza_showcase_ids` = 所有作品ID数组
2. 详情页（`/plaza/[id]`）读取 ID 列表，用 `currentIndex` state 管理当前作品
3. 使用 Pointer Events (`onPointerDown/Move/Up`) 支持触屏和鼠标
4. 拖动时 `transform: translateY(${dragY}px)` 实时跟手
5. 松手超过80px阈值：先动画滑出（`dragY = ±100vh`），350ms后更新 currentIndex，再重置
6. URL 用 `window.history.replaceState` 静默更新，不触发路由跳转
7. 外层容器改为 `position: fixed; inset: 0; z-index: 50`，彻底遮住底部 Tab

### 关键 Bug 修复记录
1. **`useSearchParams` 导入错误**：从 `@/i18n/navigation` 导入，但该模块没有导出这个 hook → 改为从 `"next/navigation"` 单独导入
2. **音量/分享按钮竖排**：重构时两个按钮被分到不同容器 → 放回同一 `flex flex-row` 容器
3. **头像灰色闪烁**：`next/image` 切换时走优化管道有延迟 → 改为普通 `<img>` 标签
4. **头像 fallback 缺失**：详情页没有橙色底+首字母兜底逻辑 → 补充 `onError` + `avatarError` state + `useEffect` 重置

### 广场详情页封面覆盖逻辑（从广场进入首页）
- "Use this dance template" 按钮改为传 `previewCover` URL 参数
- 首页读取后用 `previewCoverUrl` state 覆盖舞台封面显示
- 生成用的 `templateId` 不变
