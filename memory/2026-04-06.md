- **无频率控制**：搭话是主播口令触发（1:1），不需要频率设置

### 静态图抠图
- **方法**：OpenCV HSV 色彩空间 + 形态学操作 + 高斯羽化
- **av1 篮球小子-蓝**：✅ Qwen Vision 通过

- **ffmpeg colorkey 失败**：输出 yuv420p 无 alpha（libvpx-vp9 不支持 yuva420p 编码）

### 代码改动
- 新增 `ChromaKeyVideo` 组件：video + canvas + requestAnimationFrame 逐帧处理

- 部署 commit d5f31e0

### 踩坑记录
- ffmpeg libvpx-vp9 虽然列出 yuva420p 为 supported pixel formats，但实际编码输出为 yuv420p（丢弃 alpha）
- PIL 的 objectFit/aspectRatio + maxHeight 会在 maxHeight 被触发时裁切内容
- Coze 生成的绿幕偏黄绿，需要更宽泛的 HSV 范围
- despill：边缘区域 G 通道钳制到 min(R,B)*1.02+3

### 关键决策
- ffmpeg VP9 alpha 编码在 macOS 不可用 → 改浏览器端 canvas 处理
- Coze 绿幕偏黄绿，HSV 范围 H:35-85（比标准 40-80 宽）
- despill 只在 mask 膨胀差集（边缘区域）处理，全图处理会变色

### ChromaKeyVideo 组件实现
- video 元素 opacity:0 隐藏但保持播放
- canvas 叠在 video 上方显示处理后画面
- requestAnimationFrame 逐帧读取 video → canvas → getImageData → 绿幕检测 → alpha 修改 → putImageData
- 和静态图 ChromaKeyImage 共用相同的绿幕检测阈值
