### 1. 广场详情页分享按钮修复（完成 ✅）

**问题**：点击分享按钮无反应，剪贴板没有链接，无任何 toast 提示

**根因排查过程**：
1. 第一轮：Toast 用 `absolute` 定位，被父容器 `overflow-hidden` 截断 → 改为 `fixed`
2. 第二轮：`navigator.share` 在手机上可用，走了原生分享面板，clipboard 从未触发
3. 第三轮（根本修复）：`navigator.clipboard.writeText` 静默失败（不抛错）→ 加 `document.execCommand('copy')` fallback

**最终方案**：
```javascript
async function copyText(text: string): Promise<boolean> {
  try {
    await navigator.clipboard.writeText(text);
    return true;
  } catch {
    const el = document.createElement('textarea');
    el.value = text; el.style.position = 'fixed'; el.style.opacity = '0';
    document.body.appendChild(el); el.focus(); el.select();
    const ok = document.execCommand('copy');
    document.body.removeChild(el); return ok;
  }
}
```
Toast 用 fixed 定位，无论成功失败都显示。验收通过。
