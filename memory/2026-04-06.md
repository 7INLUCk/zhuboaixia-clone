## 搭话能力分层设计 + 搭话优先策略（01:08-01:20）

### 背景
- 部分形象经训练可实时搭话（高价档 premium），部分仅展示动作（低价档 standard）
- 动作片段无嘴型训练，物理上不能说话 → 不能合并执行
- 口令由 LLM 语义匹配，非精确文本 → 无法提前检测冲突

### 设计决策
- **搭话优先**：口令同时命中搭话和事件态动作时，优先执行搭话
- **能力徽标**：形象卡片显示 🔵可搭话 / 🟢标准
- **渐进揭示**：premium 形象在 Step 3 展示搭话区块，standard 不展示
- **无频率控制**：搭话是主播口令触发（1:1），不需要频率设置

### 实现内容
- AVATAR_LIBRARY 新增 voiceTier 字段 (standard/premium)
- Step 1 形象卡片添加能力徽标 + 已绑定形象展示徽标
- Step 3 新增搭话能力区块（仅 premium）：开关 + 规则列表 + 添加按钮
- Step 3 新增 standard 形象搭话提示（引导选择可搭话模特）
- ProductItem 新增 chatRules/chatEnabled 字段
- Commit e570b06，已部署 miaobo-b.pages.dev

### Boss 纠正记录
