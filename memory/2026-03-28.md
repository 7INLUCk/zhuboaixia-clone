### 关键教训

#### 1. 窗口尺寸必须匹配截图比例
- 截图全部 1440x900 = 16:10
- 窗口内容区必须 16:10（如 1280x800），否则 object-cover 会裁切
- macOS 标题栏 32px → 窗口总高 = 800+32=832

#### 2. 热区坐标用 SVG viewBox 最可靠
- `<svg viewBox="0 0 1440 900">` 建立与原图一致的坐标系
- 缩放时坐标自动等比变换，零误差
- 优于 CSS 百分比定位（需要手动计算缩放比）

#### 3. 叠加按钮位置不能靠目测
- 必须用 JS 像素扫描或浏览器 DevTools 测量
- image analysis 模型给的坐标有偏差（10-20px）
- 最可靠方法：canvas.drawImage → getImageData 逐像素扫描

#### 4. 叠加按钮样式必须精确匹配
- 原版用 SVG 矢量图标，不是 emoji
- 字号 14px、颜色 #8C8C8C（未选中）/ #333（选中）
- paddingLeft 15px（实测值）、行高 48px
- hover 态 rgba(0,0,0,0.04)

#### 5. TypeScript Record 联合类型推断问题
- `Record<PageId, PageConfig>` 中如果多数条目 mode:'screenshot'，TS 会推断 mode 只能是 'screenshot'
- 解决：访问时用 `(config.mode as string)` 强转
