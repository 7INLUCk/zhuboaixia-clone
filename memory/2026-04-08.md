### 改动3：预览框重构（重点）
- **删除**：底部「默认展示态」模块（6个动作chips+说明+预览按钮）
- **新增 state**：`inlinePreview: { type: 'default'|'entrance'|'exit'; videoUrl }`
- **预览框逻辑**：
  - 选中形象 → useEffect 自动切到默认展示态视频（autoPlay loop muted）
  - 无视频时 fallback 到静态 ChromaKeyImage
  - 顶部半透明标签显示当前状态：「默认展示态」/「入场片段」/「退场片段」
  - 点击入场预览按钮 → 预览框切换入场视频 + 标签变「入场片段」
  - 点击退场预览按钮 → 预览框切换退场视频 + 标签变「退场片段」
  - 右下角「返回默认」按钮（非默认态时显示）
- **关键设计**：用户感知不到后台N个片段在轮播，只看到一个完整视频
- 部署：https://852a3a51.miaobo-b.pages.dev

### Boss 关键偏好（本轮确认）
- 默认展示态不要展示动作列表/时长/chips，用户只需看到一个视频
- 标签要明确当前播放的是什么（默认/入场/退场）
- 点击预览后要能返回默认态
- 不提"随机轮播"概念，让用户觉得是完整视频
