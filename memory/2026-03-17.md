## 首页卡片底部留白修复（进行中）

### 问题
首页 Default 模式热门趋势卡片和 BottomNav 之间有大量空白

### 排查过程（多轮迭代）
1. 初始尝试：修改 VideoCard 的 aspect-ratio → 无效（aspect-ratio 与 flex stretch 冲突是 CSS 规范行为）
2. 压缩 Hero 间距 → 效果微弱且导致 UI 拥挤
3. 给 Hero 加 max-h-[200px] → 效果微弱（margins 在 max-h 外）
4. **突破点：给 section 加 min-h-[50dvh]** → iPhone 14 成功消除留白！
5. 但 50dvh 在其他设备（SE/ProMax/iPad）仍有留白
6. 最终方案：改为 `calc(100dvh - 300px)` 动态适配（待执行）

### 关键技术发现
- **CSS aspect-ratio 覆盖 flex items-stretch**：这是 CSS 规范行为，不是 bug。aspect-ratio 的优先级高于 stretch
- **解法**：容器用 `items-start`，卡片用 `h-full`（从 absolute inset-0 容器取高度）+ `aspect-[9/16]`（Tailwind class 算宽度）
- **动态视口适配**：固定百分比（50dvh）只对特定设备有效，calc(100dvh - Npx) 才能跨设备适配

### DOM 实测数据（agent-browser）
- 页面可用高度：479px（iPhone 14 viewport）
- Hero 区：~260px（占 54%）
- Section (flex-1)：~220px
- Section header（标题+标签）：~100px
- 卡片实际可用：~120px（太矮）
