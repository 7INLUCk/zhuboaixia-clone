### 3. 黑边问题调试过程

**症状**：视频两侧出现黑/暗边

**排查过程**：
1. 第一轮：以为是 `bg-black` → 改 bg-transparent → 没用
2. 第二轮：以为是模糊背景 opacity-60 → 改 opacity-90 → 没用
3. 第三轮：找到 ShowcaseContent 根容器有 `bg-[#FAFAF8]` → 改 bg-transparent → 没用
4. 第四轮：发现主视频缺少 `block`（mx-auto在inline元素上不工作）→ 重写视频容器 → 好转但还有细边
5. 第五轮：scale-110 不够大 → scale-150 → 还有
6. **根因最终定位**：CSS `filter: blur()` 在元素边缘产生暗色 halo，这是已知问题

**正确解法（待执行）**：用负 inset 延伸模糊视频超出容器，配合 overflow-hidden 裁掉暗边：
```css
top: -40px; left: -40px; right: -40px; bottom: -40px;
width: calc(100% + 80px); height: calc(100% + 80px);
```
（来源：Stack Overflow 标准解法）
