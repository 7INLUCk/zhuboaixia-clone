# 声控切镜逻辑 V2 方案

> 2026-04-07 与 Boss 确认，待落地

## 一、背景

旧逻辑问题：
- 展示口令 = 进场 + 换装（根据口令中的链接号）
- 无法区分"进场"和"指定链接切换"两种场景

新逻辑需求：
- 进场：根据"讲解中商品"自动匹配形象
- 退场：保持不变
- 指定链接切换：硬切，不播退场/入场动画

## 二、三层逻辑详解

### 第一层：进场口令

**触发**：主播说「有请模特上场」
**匹配**：当前「讲解中商品」绑定的形象
**行为**：播放入场动画进场

**异常情况**：
- 无讲解中商品 → 提示「请先在后台选择讲解中商品」
- 该商品未绑定形象 → 提示「当前商品未绑定伴播形象」

**注意**：「讲解中商品」由运营人员在后台手动切换，不是系统自动识别

### 第二层：退场口令

**触发**：主播说「请模特先下场」
**行为**：播放退场动画离场

**异常情况**：
- 场上无形象 → 提示「无伴播模特在场，无需退场」

### 第三层：指定链接口令（硬切）

**触发**：主播说「看看3号链接的模特上身效果」（口令含链接号）
**匹配**：口令中指定的链接号对应形象

**两种情况**：
1. 有形象在场 → 直接硬切（不播退场/入场）
2. 无形象在场 → 正常入场

**异常情况**：
- 该链接未绑定形象 → 提示「无N号链接的伴播形象」

## 三、Step 2 配置面板设计

### 卡片结构

三个卡片纵向排列，每个卡片包含：
1. 标题（emoji + 口令类型）
2. 流程说明（一句话 + 箭头）
3. 异常情况
4. 默认口令 + 「改口令」按钮

### 卡片1：进场口令

```
🎭 进场口令
──────────────────────────
流程：
主播说口令 → 系统匹配「讲解中商品」→ 播放入场动画进场

异常情况：
• 无讲解中商品 → 提示「请先在后台选择讲解中商品」
• 该商品未绑定形象 → 提示「当前商品未绑定伴播形象」
──────────────────────────
默认口令：「有请模特上场」 [改口令]
```

### 卡片2：退场口令

```
🚪 退场口令
──────────────────────────
流程：
主播说口令 → 播放退场动画离场

异常情况：
• 场上无形象 → 提示「无伴播模特在场，无需退场」
──────────────────────────
默认口令：「请模特先下场」 [改口令]
```

### 卡片3：指定链接口令

```
⚡ 指定链接口令（硬切）
──────────────────────────
流程：
主播说口令（含链接号）→ 系统匹配对应链接形象

两种情况：
• 有形象在场 → 直接硬切（不播退场/入场）
• 无形象在场 → 正常入场

异常情况：
• 该链接未绑定形象 → 提示「无N号链接的伴播形象」
──────────────────────────
默认口令：「看看{N}号链接的模特上身效果」 [改口令]
{N} 会自动替换为实际链接号
```

## 四、关键设计原则

1. **三个卡片平级展示**，无主次区分
2. **每个卡片完整展示**：流程 + 异常情况 + 默认口令
3. **关键词高亮**：「讲解中商品」「入场动画」「硬切」
4. **不同颜色图标区分**：🎭进场 / 🚪退场 / ⚡硬切
5. **「改口令」按钮放在口令右侧**，不打断阅读
